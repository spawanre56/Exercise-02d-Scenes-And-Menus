# Project 2: 2d Shooter
Exercise for MSCH-C220
5/3/2026
A user-controlled ship for a space-shooter game. Recently added the ability to shoot at asteroids. Created in Unity.

## Implementation
Use different assets; extra points will be awarded if you created them yourselves
Implement a variety of enemies, each with their own behavior
A larger world to explore. The camera tracks the player 
Give the game a background image 
Sounds and music (explore the Audio Source component) - added music

Created using [Unity 2022.3.45f](https://unity.com)

Assets are provided by [Kenney.nl](https://kenney.nl/assets/space-shooter-extension), provided under a [CC0 1.0 Public Domain License](https://creativecommons.org/publicdomain/zero/1.0/).

The explosion spritesheet was released into the public domain by [StumpyStrust](https://opengameart.org/content/explosion-sheet)
